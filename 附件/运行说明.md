# B02-transfer-ledger · 运行入口

项目包含本作品原创的研究样本、分析程序、复核程序与实际结果。模拟样本可随作品展示、复制和复算。

在含 analyze.py 的解压目录打开终端，使用 Python 3.11，无第三方依赖。

- 研究输入：service_days.csv。
- 独立核验依据：手算样例（见 verify.py）。
- 分析命令：`python analyze.py service_days.csv`。
- 执行 `python verify.py` 复算主试验，执行 `python stress.py` 复算反例。
- 原始证据见 `replay.json`，反例见 `stress.json`。

桌面端打开《Mira 工作流》并依次运行四轮。实际运行后由参赛者生成作品对话分享链接，填写飞书提交表。

## 复核实验 v2

请打开子目录《复核实验/复核说明》。在独立的 90 个模拟运营日上，2 分钟限等的等权净节省随预测误差改变。准确预测为 2590 人分钟；带 −2 分钟偏差时，200 次回放的中位净节省转为 −663 人分钟。 本目录原有命令继续复现原实验 v1。

# 预测不准时，限等会亏多少

这是在原实验 v1 之外新增的 v2 复核。原版海报与答辩演示保留原实验的证据。新样本及标注均为本作品自行构造，允许公开复制、演示和复算。使用 Python 3.11 标准库，从本目录运行。

```powershell
python -X utf8 prepare.py
python -X utf8 forecast.py
```

在独立的 90 个模拟运营日上，2 分钟限等的等权净节省随预测误差改变。准确预测为 2590 人分钟；带 −2 分钟偏差时，200 次回放的中位净节省转为 −663 人分钟。

输入为 `new_service_days.csv`。逐项证据在 `day_trace_rep0.csv`、`paired_repeats.csv`、`results.json`。解释与负面对照见研究报告 v2 补充章节。
